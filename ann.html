What is an ANN?

An Artificial Neural Network (ANN) is a densely connected network inspired by the human brain. Every neuron in one layer connects to every neuron in the next — this is called a fully connected or dense architecture.

Unlike CNNs, ANNs have no spatial awareness. A 28×28 image is flattened into a single vector of 784 numbers before being processed.

What is AdamW?

AdamW (Adam with decoupled Weight decay) is the optimizer that updates the weights during training. It combines:

  • Gradient (g): Direction of steepest loss descent
  • Momentum (m): Smoothed average of past gradients
  • Velocity (v): Smoothed average of squared gradients
  • Weight Decay (λ·w): Shrinks weights to prevent overfitting
AdamW Update Rule
mt = β₁·mt-1 + (1-β₁)·gt
vt = β₂·vt-1 + (1-β₂)·gt²
w = w - lr · m̂t/(√v̂t + ε) - λ·w
The red term is weight decay — unique to AdamW vs standard Adam

Input → Forward Prop → Loss → Backprop → AdamW Update → Repeat

Step 2: Forward Propagation

The 784 pixels of your image are flattened and fed into the Input Layer. The data flows left-to-right through the hidden layers.

Each connection multiplies the signal by a Weight, and each node applies an Activation Function (ReLU) to decide how strongly it should "fire".

Step 4: Backpropagation

To learn from its mistake, the network calculates the Gradient (the direction of steepest descent) of the Loss with respect to every single weight using the Chain Rule of calculus.

Notice the signal flowing backwards (Right-to-Left):

  • Red Pulse: Negative gradient (decrease weight)
  • Blue Pulse: Positive gradient (increase weight)

Step 5: Weight Update (AdamW)

Instead of just subtracting the gradient directly, modern networks use advanced optimizers like AdamW to adjust the weights smoothly.
