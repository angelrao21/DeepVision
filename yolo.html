YOLO (You Only Look Once)

Understanding real-time, single-shot object detection

YOLO (You Only Look Once) revolutionizes object detection by framing it as a single regression problem, straight from image pixels to bounding box coordinates and class probabilities. Unlike older methods that propose regions first, YOLO looks at the entire image at once, making it extremely fast and suitable for real-time applications.

Grid Division – Spatial Splitting

How it works: YOLO divides the input image into an S × S grid. If the center of an object falls into a grid cell, that grid cell is responsible for detecting that object.
7×7
3

Bounding Box Prediction – Regression

How it works: Each grid cell predicts multiple bounding boxes and confidence scores. These scores reflect how confident the model is that the box contains an object. Many cells predict bad boxes, resulting in a mess of thousands of overlapping predictions.

4

Class Probabilities – Classification

How it works: Simultaneously, each grid cell predicts class probabilities (e.g., Person, Car, Dog). Hover over a grid cell to see the highest probability class it predicted.
5

Non-Maximum Suppression – Filtering

How it works: YOLO uses NMS to clean up the messy predictions. It first discards all boxes with low confidence. Then, for remaining boxes that overlap heavily (high Intersection Over Union - IOU), it keeps only the one with the highest confidence.

Final Detection – Output
